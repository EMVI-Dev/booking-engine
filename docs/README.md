# TravelEngine docs

**Start here: [product/overview.md](product/overview.md).** It describes the product, lists what ships, and maps every doc in this folder.

TravelEngine is the booking product. **EMVI Technologies** is the company. Docs are grouped by who reads them: `product/`, `commercial/`, `features/`, `engineering/` and `audits/`. Agent and tooling files (`AGENTS.md`, `CLAUDE.md`, `.ai/rules`) stay at the repo root.

If a doc and the code disagree, the code wins: fix the doc in the same change.
